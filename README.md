# 🧑‍🦽 Fall Detection


A **MediaPipe-based Python application** that detects when someone falls on the floor and **alerts their caregiver** in real-time.

This project is designed for safety monitoring — especially helpful for elderly care or assisting individuals at risk of falls.

---

## 🚀 Features

- 📹 **Real-time fall detection** using a camera  
- 🧠 Uses **MediaPipe pose estimation** to analyze human posture and movement
- 📢 Sends alert when a fall is detected
- 🕹️ Simple, intuitive Python interface

---

## 📦 Getting Started


### 🛠 Prerequisites

Before running the project, ensure you have:

- Python 3.8 or later  
- A webcam or camera module  

---

## 🧩 Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/naiksiddarth/fall-detection.git
   cd fall-detection
   ```
2. **Create a virtual environment (recommended)**
   ```bash
   python -m venv venv
   source venv/bin/activate   # macOS/Linux
   venv\Scripts\activate      # Windows
   ```

3. **Install dependency**
   ```bash
   pip install -r requirements.txt
   ```
---

## ▶️ Running the App
```bash
python main.py
```
